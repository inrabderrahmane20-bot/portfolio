## Localization and market pages

The main site language switcher displays English, French, or Spanish client-side; those versions do not have separate crawlable URLs. The services landing page is separately available in English, French, Spanish, and Arabic at `/services`, `/fr/services`, `/es/services`, and `/ar/services`; these equivalent pages have reciprocal `hreflang` links. Arabic is also listed as a spoken language in the existing portfolio.

The current repository contains seven public project records. No claim of fifteen projects is made. The existing education content identifies an Engineering State Engineer Degree; it does not support a Master's-degree claim. The site has no dedicated service pages for individual countries; create those only when there is original, useful content for each market. The shared services page can serve remote clients without implying local offices outside Morocco.

Search Console and Bing Webmaster Tools ownership verification must be completed by the domain owner before sitemap submission. Market-specific keyword research should guide any later country pages.
